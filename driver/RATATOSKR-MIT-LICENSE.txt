### Upstream Credits & Acknowledgments

This project builds upon, references, and incorporates architectural design patterns from:

1. **Project Barry / Barry Launcher** (https://github.com/project-barry/barry-launcher, https://github.com/project-barry/pb-os)
   - Created by lavachemist and the Project Barry community (GPL-2.0 / GPL-3.0 / MIT).
   - Pioneered bottom-screen Gamescope dual-display input architecture, raw-to-screen coordinate mapping, multi-touch gesture processing, and hardware sensor node discovery on the AYN Thor.

2. **Armada OS** (https://armadaos.dev / https://github.com/armada-linux)
   - Created by the Armada Linux engineering team.
   - Provided `armada-run-bottom`, device-env specifications, DRM/DSI backlight drivers, and dual Gamescope display plumbing for the Qualcomm SM8550.

3. **Decky Loader** (https://github.com/SteamDeckHomebrew/decky-loader)
   - Created by the SteamDeckHomebrew community (GPL-3.0).
   - Provided the plugin runtime, IPC socket bridge, and frontend Quick Access Menu (QAM) framework for SteamOS Game Mode.
